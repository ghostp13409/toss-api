Today, I’m super proud to share a project I’ve been working on for quite some time: **toss-api**!

My initial motivation was simple: learn Rust by building something truly useful that solves a real problem for developers like me.

toss-api is a lightweight, Rust-based TUI API client built with speed and performance at its core. If you’re a Linux developer who loves a Vim-based workflow, this was made for you! It comes packed with all the essential features you'd expect—full REST API support, scripting, and authentication (Basic, API Keys, and JWT Bearer). Plus, you can easily import and export your Postman and OpenAPI collections!

**The feature I’m most excited about:** toss-api can parse endpoints directly from your codebase! With just a single command, it scans your routers and controllers across almost all major frameworks and builds an organized collection for you. It even detects the request body formats in your POST actions and automatically generates placeholder JSON bodies! Oh, and you can copy results instantly with just a single keypress.

While it runs on Windows and macOS, it’s currently best experienced on Linux while I iron out a few platform-specific bugs.

I’d love for you to try it out! You can grab the latest version on crates.io or check out the official GitHub repo. Any feedback, bug reports, or feature requests would mean the world to me! 🦀💻
